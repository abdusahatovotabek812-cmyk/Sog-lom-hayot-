# Sog'lom turmush tarzi

Bu loyiha sog'lom hayot tarzini targ'ib qilish uchun yaratilgan veb-sayt. Sayt ovqatlanish, mashqlar, uyqu rejimi va kundalik odatlar bo'yicha amaliy yo'l-yo'riqlar beradi.

## Xususiyatlar

- **Maqsadlar**: Sog'lom odatlarni shakllantirish uchun motivatsiya va progress kuzatuvi.
- **Ovqatlanish**: Muvozanatli ovqatlanish bo'yicha tavsiyalar va kaloriya hisoblari.
- **Mashqlar**: Kundalik mashq ketma-ketligi va yugurish trekeri.
- **Rejim**: Kunlik reja va shaxsiy vazifalarni boshqarish.
- **Aloqa**: Foydalanuvchilar bilan bog'lanish uchun forma.

## Texnologiyalar

- HTML5
- CSS3
- JavaScript (ES6+)
- Local Storage (ma'lumotlarni saqlash uchun)

## Ishga tushirish

1. Repozitoriyani klonlang:
   ```
   git clone https://github.com/username/sog-lom-hayot.git
   ```

2. `index.html` faylini brauzerda oching.

Sayt to'liq statik bo'lib, server talab qilmaydi.
